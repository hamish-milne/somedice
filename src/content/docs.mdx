# SomeDice Documentation

Welcome to SomeDice! This is a powerful dice calculation and probability tool for tabletop gaming and statistical analysis.

## Getting Started

SomeDice allows you to write simple scripts to calculate dice probabilities, simulate rolls, and analyze outcomes.

### Basic Syntax

Here are some basic examples:

```
output "damage" 1d6 + 2d4
```

This calculates the probability distribution for rolling one 6-sided die plus two 4-sided dice.

### Variables

You can define variables to make your calculations more readable:

```
function attack_damage
  result 1d20 + 5
end
```

## Features

- **Probability Distribution**: Calculate exact probability distributions for complex dice expressions
- **Statistical Analysis**: View cumulative probabilities and individual outcomes
- **Loop Operations**: Iterate over ranges and perform complex calculations
- **Named Outputs**: Label your results for easy identification
